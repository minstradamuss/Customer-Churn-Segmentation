# Data

Main source: UCI Machine Learning Repository — Online Retail II.

Official page:
https://archive.ics.uci.edu/dataset/502/online+retail+ii

Direct ZIP:
https://archive.ics.uci.edu/static/public/502/online+retail+ii.zip

The raw Excel dataset is not committed to keep the GitHub repository small.
The public source contains 1,067,371 transaction rows from a UK-based online retailer.

`data/processed/` contains compact real-data-derived analytical checkpoints used by the already-executed notebook.
The end-to-end raw-data pipeline is in `src/full_pipeline.py`.

No synthetic customer transaction rows are included in this version.
